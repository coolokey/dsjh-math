# 搬移檢查紀錄

搬移來源：大溪國中「溪中魔『數』領域網站」的已登入 Weebly 編輯器。

## 保存成果

- 導覽共 36 項，保留名稱、原始順序及父子分類；其中標準頁面 27 頁、外部連結項目 9 項。
- 完整擷取 12 個自訂 HTML 框架，補回歷年獲獎表格與舊行事曆嵌入附件。
- 成功下載 2,167 個素材，合計約 299 MB；包括 51 份 PDF、2 份 Word 文件、原站圖片、縮圖及主題素材。
- 20 組原相簿共 1,038 個照片項目：展示備份縮圖，點擊打開備份原圖；每組依原縮圖清單排序，沒有重複加入前幾張預載原圖。
- 本機原始備份保存在專案 `backup/`，不推送原始後台擷取檔。

## 連結處理

檢查 101 個相異外部連結：59 個可連線，18 個確定回傳 HTTP 404，24 個因網路逾時、驗證或存取限制無法確認。已將確定失效的超連結移除，保留原文字；在公開內容中共涉及 22 處連結引用。其餘維持原目的地；可成功升級的 HTTP 網址改採 HTTPS。

外部相簿、Google Sites、部落格和 YouTube 仍由原服務提供。連結當時可連線不等於影片每個地區都能播放，也不代表外部服務已完整離線備份。

## 平台功能差異

- Weebly 相片輪播改為本機相簿及原圖對話框。
- Weebly 留言表單保留歷史標題與欄位文字，所有欄位停用，移除提交操作並明示無法送出。
- Weebly 站內搜尋未移植，保留原分類與連結供瀏覽。
- 地圖改為大溪國中位置的 Google 地圖連結。
- 保留原第三方訪客計數器來源，數值仍取決於原計數器服務。

- 對照 36 項導覽資料及每頁實際導覽，名稱、順序、階層一致。

- 下載檔案 SHA-256 與素材清單一致，圖片皆通過解碼驗證，51 份 PDF 皆具有 PDF 檔頭。

- 36 頁通過手機版寬度檢查；實測子分類導覽、相簿原圖開啟與行事曆 PDF 連結。
- 已執行獨立程式碼複核，照片原圖、歷史表單與自訂框架問題修正後通過。
